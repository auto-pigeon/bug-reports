# Auto-Pigeon bug reports

This is the public issue tracker for Auto-Pigeon. Report bugs here — by hand, or through the
**Report a bug** action inside Auto-Pigeon, which files an issue in this repository for you.

## Everything you post here is public

Issues, comments, attachments and screenshots in this repository can be read by anyone on the
internet, and they stay readable after the bug is fixed. Before you submit, remove:

- **secrets** — passwords, tokens, API keys, session cookies, `.env` contents, private URLs;
- **private data** — names, e-mail addresses, IP addresses, file paths that reveal your username
  or machine, anything about another person;
- **assets you may not share** — maps, WADs, textures, models, palettes or PAK files you did not
  make or have no right to publish. Describe the problem, or attach a minimal file you made
  yourself, instead.

A report generated from inside Auto-Pigeon shows you its full text before it is sent. Read it.

## Security problems do not go here

Do **not** open a public issue for a vulnerability or anything security-sensitive. Report it
privately through GitHub's private vulnerability reporting:
<https://github.com/auto-pigeon/bug-reports/security/advisories/new>. Only the maintainers can see
it.

## Your reports stay yours

This repository contains no Auto-Pigeon source code, and no software licence applies to the issues
filed here. Posting a report does not transfer ownership of what you wrote or attached; it is
published under [GitHub's Terms of Service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service),
which let GitHub and other users view it on GitHub. If code is ever added to this repository, it will
carry its own explicit licence.
